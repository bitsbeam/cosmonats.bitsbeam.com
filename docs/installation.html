Installation

Requirements: Ruby ≥ 3.2, NATS Server ≥ 2.14 with JetStream enabled (install guide)

Optional gems — not installed with cosmonats, add them only for the features you use:

Feature Gems
Monitoring UI (Cosmo::Web) rack
Health check HTTP server (/health, /ping) rack, webrick

Warning

Cosmo::Web ships with no authentication and no CSRF protection, yet it exposes destructive actions (retrying and deleting jobs, pausing streams, running and deleting crons). Never expose it unprotected.
